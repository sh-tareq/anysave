          Shortcuts

          • ⌘V / Ctrl V anywhere on this page: download the copied link
          • Space pause or resume the selected download · Delete remove it · Enter open it
          • ⌘A select all · / search · Esc clear the selection
          • On a website, hold Alt while clicking a download link to let Chrome download it, or Ctrl to make AnySave do it.
          • A batch pattern like https://example.com/part[01-10].zip adds all ten files.
          • Paste a SHA-256 checksum after a link and AnySave checks the finished file against it.
